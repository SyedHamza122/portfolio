## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/SyedHamza122/portfolio.git
```

Go to project folder

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Create production build

```bash
npm run build
```
